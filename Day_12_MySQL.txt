Set Operators:
==============
Union : combines results from two queries and remove duplicate rows. columns must have the same number and type.

Union All : combines results from two queries. including duplicates. columns must have the same number and type.

Intersect : returns rows that are common to both queries. column must have the same number and type.
Note : MySQL doesn't support intersect directly

Minus : returns rows from the first query that are not present in the second query colums must have the same number and type.
Note : MySQL doesn't support Minus directly
